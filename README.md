## 🚀 Projets phares

Trois projets persos construits pour explorer en profondeur le triptyque **Cloud / Sécurité / Automatisation** :

### 🛡️ [Aegis-Ops](https://github.com/SebaAbdou/aegis-ops) — Architecture Cloud DevSecOps & GitOps
Infrastructure AWS en IaC (Terraform/Ansible), cluster K3s isolé avec VPN WireGuard, pipeline DevSecOps complet (Jenkins → Trivy → ArgoCD → Nmap).
`Terraform` `Ansible` `AWS` `K3s` `Jenkins` `ArgoCD` `WireGuard`

### 🤖 [AIOps](https://github.com/SebaAbdou/aiops) — Détection d'Anomalies & Réentraînement Automatique
Pipeline temps réel sur Kubernetes détectant les anomalies infra (DDoS, latence, erreurs HTTP) avec un modèle RandomForest — **ROC-AUC de 95,61%**. Boucle MLOps complète avec réentraînement automatique et rollback.
`Kubernetes` `Python` `scikit-learn` `Prometheus` `Grafana`

### 🔧 [Infra-Ops Toolkit](https://github.com/SebaAbdou/infra-ops-toolkit) — Automatisation & System Hardening
Framework Bash/Python d'administration système multi-distributions (RHEL/Debian) : hardening SELinux, sauvegardes chiffrées GPG AES-256, gestion robuste des erreurs.
`Bash` `Python` `SELinux` `RHEL` `Debian`
